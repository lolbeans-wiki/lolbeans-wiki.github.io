How to use any model as your player model in Lolbeans!

This guide uses a third-party userscript to change how your character looks in your browser. The script runs on lolbeans.io and modifies the game's page locally. Review it before installing, and only use code and models you trust.

  1. I believe chrome is needed for this, I tested on firefox and it doesn't work
  2. install extension CodeTweak, made by e!, on chrome web store
  3. Manage the extension and enable Userscripts
  4. Copy the entire script from the bottom of this page
  5. Click on the extension then press the plus icon
  6. Simply copy and paste into the CodeTweak editor, and save the script
  7. Load lolbeans.io, and press escape, and then you will have the menu to load skins
  8. The editor accepts .glb files, I personally use sketchfab to find these
